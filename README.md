# NEUROIQ — Android cognitive practice app

Turkish, offline-first cognitive practice app. The Android Studio project is in `android/`; the web app source is in `www/`.

## Features
- 500 procedurally generated practice questions across five categories and five difficulty levels.
- Fixed and adaptive 20-question modes.
- Local test history and category performance summaries.
- Offline use; test history remains on the device.

## Build an APK with GitHub Actions
Open **Actions**, choose **Build NEUROIQ APK**, and run the workflow. When it finishes, download the `NEUROIQ-debug-apk` artifact from the run.

## Important
This is an entertainment-oriented reasoning practice app. Its score is an in-app performance index, not a standardized IQ score or clinical assessment. The procedural question bank has not undergone psychometric validation.
